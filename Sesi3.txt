UPDATE & DELETE

Update -> mengubah data di suatu table

Syntax:
UPDATE [table_name]
SET column_name = new_value
[,column_name2 = new_value2]
[WHERE conditions]

Delete -> menghapus data pada suatu table

Syntax:
DELETE FROM [table_name]
[WHERE conditions]
